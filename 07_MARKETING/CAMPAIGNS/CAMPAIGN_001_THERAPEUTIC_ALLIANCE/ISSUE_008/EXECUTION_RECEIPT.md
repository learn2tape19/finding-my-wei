## Execution lessons

1. **GraphQL enum values must be unquoted.** Buffer's GraphQL schema uses enum types (`PostType`, `PostTypeFacebook`, `ShareMode`, `SchedulingType`). Values like `post`, `story`, `customScheduled` must appear unquoted in mutations — `json.dumps()` wraps them in quotes, causing `GRAPHQL_VALIDATION_FAILED`.

2. **GraphQL object keys must be unquoted.** Standard JSON `{"key": "value"}` syntax fails in GraphQL input objects. Keys must be bare identifiers: `{key: value}`.

3. **Buffer Free plan enforces a 10 scheduled post limit per channel.** The Instagram channel hit this cap after 10 posts. Facebook channel was unaffected (only 5 posts). Essentials plan removes this restriction.

4. **Buffer `editPost` with `saveToDraft: false` does not preserve existing assets/metadata.** Moving a draft to scheduled via `editPost` requires resending all fields. Simpler to delete and recreate.

5. **Buffer `deletePost` returns `DeletePostPayload` union (`DeletePostSuccess | VoidMutationError`), not `PostActionSuccess`.** Different return type than `createPost`.

6. **Buffer `post` query requires `input: {id: "..."}` not `id: "..."` as a direct argument.**
