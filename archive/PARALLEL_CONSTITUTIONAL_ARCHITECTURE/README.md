# Finding

The repository contains two directories whose names differ only by case but whose contents represent different architectural generations.

This is not a harmless naming inconsistency. It creates ambiguity about constitutional authority.

`00_Constitution/` contains the ratified Repository Constitution v2.0 and the broader constitutional corpus.

`00_CONSTITUTION/` contains a four-file FC/ARCH architecture package:

- `MASTER_REPOSITORY_MAP.md`
- `REPOSITORY_ARCHITECTURE.md`
- `ARCH-002_IMPLEMENTATION_SPEC.md`
- `ARCH-002_WORK_ORDER.md`

The parallel package is therefore being reconciled into the canonical architecture rather than treated as a second constitution.
