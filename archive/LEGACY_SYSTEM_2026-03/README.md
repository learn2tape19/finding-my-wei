# Why this generation was retired

`_system/` was an early AI-centered execution environment built around OpenClaw/Taylor Swain, daily TODAY files, three-project balancing, persona/memory files, and Notion mirroring.

It served a real purpose in March 2026. By September, its project state, tool assumptions, local paths, and mandatory cadence were stale and conflicted with the ratified Constitution, current operating-state doctrine, healthy dormancy, and the proven production playbook.

The directory has now been physically removed from the reconciliation branch.

---

# Disposition summary

Historical AI persona/onboarding/context files (`SOUL`, `MEMORY`, `USER`, `CLAUDE_WELCOME`, Sidekick agent guides) are preserved through Git as design history, not current authority.

OpenClaw and status-control files (`OPENCLAW_LAUNCHER`, `MASTER_CONTROL`, `TODAY`, `INDEX`, `PROJECTS_MAP`, sync instructions) are retired because their source surfaces and assumptions no longer exist.

`WEEKLY_PROJECT_BALANCE` is preserved historically but its forced 48-hour-touch rule is explicitly superseded.

`RULES.md` contained useful simplicity instincts but also obsolete absolutes; durable principles now live under current constitutional and operating standards.

# Principles preserved

- Prefer execution to organizational theater.
- Keep priorities bounded when useful.
- Tie work to outcomes.
- Surface Founder decisions clearly.
- Avoid unnecessary parallel documents.
- Preserve explicit human approval for consequential actions.
- Use AI to reduce friction rather than create administrative work.

These principles now operate under the Constitution, `OPERATING_STATE.md`, `START_HERE.md`, and `01_OPERATING_SYSTEM/`.

# Explicit supersessions

- every project must receive a meaningful touch every 48 hours;
- the estate must always focus on exactly three projects;
- Tao may receive no new content;
- work must originate from `_system/TODAY.md`;
- Notion is a required daily mirror;
- OpenClaw/Taylor is the master execution engine;
- AI persona or memory files establish institutional truth.

Current doctrine permits unequal attention and healthy dormancy.
