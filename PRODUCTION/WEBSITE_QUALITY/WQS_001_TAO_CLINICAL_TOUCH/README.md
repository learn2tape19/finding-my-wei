## Overview

This directory contains the complete governance record for Website Quality Sprint 001, following the four-gate model:

1. **Gate 0 — Observation** (Current)
   - Public crawl and baseline establishment
   - Factual inventory of all public content
   - Zero modifications

2. **Gate 1 — Understanding**
   - Editorial alignment audit
   - Technical and accessibility assessment
   - Treatment plan development
   - Awaiting approval before proceeding

3. **Gate 2 — Intervention**
   - Approved modifications only
   - Small, verified phases
   - Complete documentation
   - Pending Gate 1 approval

4. **Gate 3 — Reflection**
   - Baseline comparison
   - Impact assessment
   - Institutional knowledge capture
   - Pending Gate 2 completion

## Principles

This sprint is governed by:

- **Constitutional Principle** — The website is the public expression of the institution
- **North Star** — A first-time visitor immediately understands what the Tao is, who Drew is, why the work is different, how ideas connect, where to go next
- **Principle of Invitation** — Reduce friction between curiosity and understanding; invite through clarity
- **Principle of Minimal Necessary Change** — Only change what needs to change to strengthen clarity, credibility, accessibility, performance, discoverability, or institutional coherence
- **Principle of Successive Stewardship** — Every change is reversible, documented, justified, and verified
