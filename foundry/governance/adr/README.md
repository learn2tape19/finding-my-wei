# Architectural Decision Records (ADR)

**Directory:** `/foundry/governance/adr/`  
**Purpose:** Constitutional architectural decisions for Foundry institutions  
**Authority:** Founder approval required for all ADRs  

---

## Current ADRs

### ADR-001: Architectural Preflight Requirement
**Status:** Proposed (Accepted upon MC-001 Integration)  
**Date:** July 29, 2026  
**Scope:** Foundry governance  

Every Foundry component shall complete an Architectural Preflight before implementation begins.

[Full Document](ADR-001_ARCHITECTURAL_PREFLIGHT.md)

---

## ADR Process

1. **Propose** — Document decision in ADR format
2. **Review** — Architectural preflight completed
3. **Approve** — Founder approval recorded
4. **Accept** — Upon institutional integration
5. **Archive** — Permanent institutional record
