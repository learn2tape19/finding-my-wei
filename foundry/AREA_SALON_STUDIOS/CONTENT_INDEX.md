## Use an existing piece

1. Find its campaign, source ID and exact version. Read any correction or supersession note.
2. Open the export/package and its matching copy. Preserve slide order, dimensions, timing, credits, links, captions and native-feature instructions.
3. Confirm current offer accuracy, permissions, destination and the existing publishing queue. Reuse must not imply outdated availability.
4. Retain authorization for the specific release. Cataloging a draft is not approval to publish it.
5. After distribution, record platform/account, object ID, actual timestamp/timezone, exact asset hash and caption, live permalink and native elements. A repost is a new event linked to the same asset.
6. Attach results at comparable ages, then record the decision to reuse, revise or retire. Unknown is not zero.

The structured register currently keeps absent evidence explicit. Do not convert a source record, generated image, prior assistant assertion, Notify Me event or elapsed calendar time into verified publication.

## Source preservation boundary

This public index points to protected originals rather than copying private drafts or business data into public Git history. Adobe metadata/preview links are source locators, not binary backups. Some rendering recipes require source-path rebinding; a clean-room re-render was not performed. See the gap list in the review before claiming complete institutional preservation.
