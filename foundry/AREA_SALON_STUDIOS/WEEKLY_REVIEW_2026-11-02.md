## Lessons converted into working rules

| Observation | Rule for future work | Acceptance evidence |
|---|---|---|
| Old downloads looked like the latest revision | One approved master ID; explicit version/date; mark older exports superseded in handoff notes | Filename/master ID recorded beside final platform post URL |
| A correct source did not guarantee a correct final frame | Review the actual encoded MP4, especially the final CTA, on a phone before release | Beginning/middle/end visual check and full playback |
| Overlays hid the property being marketed | Keep chairs, workstations and space visible; use compact text/local gradient | Mobile review confirms furniture and CTA are both readable |
| Static sticker artwork was confused with native capability | Track “artwork ready,” “native setup complete,” and “published” separately | Actual link/poll/mention checked in Instagram |
| Drafts and queues risk duplicate posts | Reconcile Buffer draft/queue state after native posting | One live post per intended item; no duplicate queued copy |
| Historical status contradicted newer releases | Put dated current truth first; retain old evidence as history | Latest source and confirmation method shown |
| New layouts could disrupt inquiry routing | Preserve original form identities and verify authorized test receipt | Named test with inbox receipt, without claiming broader coverage |
| Building was easier to measure than business impact | Measure reach-to-inquiry-to-tour outcomes | Dated metrics with source and comparable denominator |
